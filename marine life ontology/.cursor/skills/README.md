# Ontology authoring skills

Project skills for editing the scuba / GoDive marine life knowledge graph. Grounded in W3C RDF 1.2, SHACL 1.2 Core, and R2RML.

| Skill | Use for |
|-------|---------|
| [`rdf-12-ontology`](rdf-12-ontology/SKILL.md) | Vocabulary & instance Turtle (authoring) |
| [`shacl-constraints`](shacl-constraints/SKILL.md) | Shapes / restrictions / validation |
| [`r2rml-mapping`](r2rml-mapping/SKILL.md) | RDB/JSON→SQLite→RDF mappings |

Workspace-root wrappers under `GoDiveMVP/.cursor/skills/` point here so Cursor can discover the skills from the app repo.

Also see rules in `../rules/` (`marine-kg-project.mdc`, `rdf-turtle.mdc`, `shacl-shapes.mdc`, `r2rml-mappings.mdc`).

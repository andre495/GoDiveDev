## Stack and entry

- **SwiftUI** UI, **SwiftData** persistence (dual on-disk stores). **Deployment target: iOS 26** (`IPHONEOS_DEPLOYMENT_TARGET` 26.0 / 26.2) — agents must not assume iOS 18 is current (see **`.cursor/rules/ios-26-deployment-target.mdc`**).
- **Hybrid cloud (Option A — live):** **Apple CloudKit** private DB syncs the **user dive log** across the user’s devices; **Firebase** (Auth + Firestore + Storage) handles the **social directory**, **friends graph**, **friend-visible dive projections** (notes/media opt-in), **developer-owned catalogs**, and **anonymized community SiteReports + sightings** (default on → activity creates a 1:1 SiteReport; tags attach sightings with `siteReportId` → `communitySiteReports` / `communitySightings` → scheduled `species_similarity.json`; Settings opt-out). Owner CloudKit remains source of truth. Boundaries: **`cursor/hybrid_cloud_sync_boundaries.md`**.
- **Public docs:** GitHub Pages user guide (**`docs/`** / MkDocs) includes an **Ontology** section; CI exports pyLODE vocabulary HTML + a **static** graph visualizer from **`marine life ontology/`** into **`site/ontology/`** (`export_github_pages.py`). Ontology namespace **`mlo:`** → **`https://www.godiveios.com/marine-life/`**.
- **Maps:** **MapKit** when no Google key is configured. **Google Maps SDK** when **`Config/GoogleMapsSecrets.plist`** contains a valid **`APIKey`** (**`GoDiveMapEngine`**); **Explore**, dive overview, and site coordinate picker switch automatically. Optional **`MapID`** for hybrid POI styling. Launch arg **`-GoDiveMapEngineGoogle`** still forces Google without secrets (tooling).
- **`GoDiveMVP/GoDiveMVPApp.swift`:** `@main`; production SwiftData via **`AppModelContainer.loadProduction()`**; **`AccountRemoteDataPopulation`** on session restore / Sign in with Apple (Firebase + iCloud reconnect + merge); **Sign in with Apple** keeps the launch overlay up and only attaches **`currentProfile`** after population (including SwiftData container swap) so the main shell never reads a torn-down store. **`AppLaunchOverlay`** through session restore, remote account population, and first Home paint (**`isHomeLaunchChromeReady`** — lifetime stats first; carousel JPEG seed no longer holds splash; idempotent mark on any successful Home apply while splash waits, plus an **8 s** failsafe so a cancelled rebuild cannot leave splash up forever). After splash dismiss, **`AppLaunchPostOverlayPresentation`** quiet windows keep Home interactive: launch carousel media-index starts under splash (background `ModelContext`; post-chrome defer **0**) and picks paint immediately from soft **`previewJPEGData`** (brief quiet gradient only until the index resolves — no spinner); PhotoKit still/video upgrades replace those previews in place without blocking taps; media enrich **500 ms** (lifetime stats already include Top Species / Top Buddies on the launch path), CloudKit dive-log kick **500 ms**, PhotoKit carousel warm **750 ms** (warm owns the serial video gate so page ensures do not double-queue), idle Field Guide / Explore catalog binds **1 s** (immediate when that tab is selected), soft JPEG persist **1 s** after warm, marine **uuid→commonName** map (off-main) + dive-site bind **2 s** then a light rebuild for species names — Home does not bind the full **`MarineLife`** catalog (owner-tagged UUIDs only for overlays; Field Guide still binds its own list). Photo stills warm at hero quality (slide **0** first), session-pinned; Home videos use **`HomeCarouselVideoSessionCache`** (**`requestPlayerItem`**, medium rendition, **serial** PhotoKit gate, priority / slide **0** first, retries + late-arrival cache) into muted **`HomeCarouselMutedVideoPlayer`** (**`DiveMutedVideoAudioSession`** ambient + mix-with-others so Music / other playback keeps playing; playback gated to the **selected scroll page**; Home featured media uses **`ScrollView`** paging (not a looping paged **`TabView`**) so swipe reliability matches dive Media; last→first auto-advance jumps without scrubbing middle slides; video surfaces are non-interactive; slide open uses a UIKit tap on the paging scroll view (pans stay primary); eager **HStack** paging; Home top chrome passes hits through empty header/wordmark band; bottom chrome hugs control-row height). Active + **next** slides prepare streams (not wrap-previous). Missing **`previewJPEGData`** fills run **after** warm. Carousel excludes library videos **> 30 s**. **`AccountSession`** + **`AppSessionRootView`** gate **`ContentView`** behind **Sign in with Apple** (**`SignInView`**). **Launch mock seeding is off** (**`MockDataSeeding.isLaunchSeedingEnabled`** default **`false`**). **Launch maintenance:** **`AppLaunchMaintenance`** — essential tier (dive # backfill, buddy migration, marine catalog seed, ownership/hybrid migrations) on a background **`ModelContext`** at attach; **`DiveSiteReferenceCatalog.prewarmBundledReference`** + Explore All Sites session snapshot delayed ~**2.5 s** (not immediate) so decode does not race Gate 2/3; **deferred tier** (~**2 s**) for CDN refresh, site/track backfills, preview JPEG backfill, Firebase profile sync; PhotoKit media prune + cloud-id backfill via **`DiveMediaPhotoKitLaunchMaintenance`** after Home chrome + **8 s** (coalesced; not on MainActor identity reconcile). **`GoDiveCloudKitDiveLogSyncKickstart.kick`** waits until Home chrome is ready plus **500 ms**. Session restore ownership healing uses count/predicate scans (not full-table materialization); marine seed skips the bundled JSON read when file size/mtime matches the last applied fingerprint. First Home aggregate paints from owner dives immediately (**`initialHomeRebuildDeferNanoseconds = 0`**) with **Top Species** / **Top Buddies** from denormalized sightings + buddy tags and a thin owner-tagged common-name resolve (full catalog name map still loads ~**2 s** after chrome for overlays / late tags). **Root tabs:** All tab destinations stay mounted (iOS 26 `TabView` can freeze lazy `Color.clear` placeholders — do not wrap tabs). Selection is synced from UIKit **`didSelect`** (**`RootTabBarSelectionSync`**). Idle cost: Home keeps always-live owner dive/snorkel `@Query`s; Explore mounts **`OwnerDiveActivitiesQueryBridge`** while selected; Field Guide / Explore catalog binds wait for Home chrome + **1 s** when idle (immediate when selected); WaterBubble display links pause off-tab; Field Guide has no root dive query (fetch-by-id destinations); Search index warmer mounts only after the Search tab is selected. Logbook row cache waits until the **Logbook** tab is selected and refuses to latch / apply an empty list from a transient empty `@Query` flash while activities exist; Explore scope cache + catalog loads run only while Explore is selected; session-cache All Sites seed still helps first Explore open; does not cancel that rebuild on spurious disappear, and waits for My Sites pins only while a rebuild is in flight (then falls back to All Sites). **MapKit / Google warm-up:** **`MapKitWarmup`** / **`GoogleMapsWarmup`** run when the **Explore** tab is selected (off-screen map views — no launch **`Map`** in the tree), with a **2.5 s** fallback after the main shell appears if Explore was never opened — skipped under UI tests. Post-sign-up celebration configures Google SDK only (no hidden map) before shell prewarm so Explore does not spawn duplicate **`CCTClearcutUploader`** instances; **`GMSServices`** configures lazily on first map view, not in **`didFinishLaunching`**. **Crash analytics:** **`CrashReportingService.startAtLaunch(container:)`** in **`ProductionAppRoot.task`** — subscribes **`CrashDiagnosticsCollector`** to **MetricKit** (**`MXCrashDiagnostic`** → stored report on the launch after a crash; **`MXMetricPayload`** / **`MXAppLaunchMetric`** → local **`[MetricKit.Launch]`** + Application Support **`metrickit-launch-summary.txt`** for Organizer-equivalent time-to-first-draw histograms — not uploaded; usually delivered next day / without a debugger) and checks the **`CrashSessionMarker`** `UserDefaults` lifecycle marker (previous session still *foreground* at launch → **Abnormal exit** report); scene-phase changes keep the marker in sync. DEBUG **`[LaunchTimeline]`** also marks **`process_start`** / **`first_frame`** for local cold-launch deltas. **`CrashBreadcrumbTrail`** persists last **~24** UI breadcrumbs + coarse context (root tab, dive overview tab/detent, media count/selection/kind, featured id, open sheet, last action, orientation, dive id) across the dying session, refreshes the session-marker details on each breadcrumb (so abnormal exits aren’t stuck on launch-time context), and freezes them into report details at next launch (MetricKit + abnormal exit) while clearing the live trail **and** UI context so a short new-launch breadcrumb list is not paired with stale dive/media state. Reports persist as **`CrashReportRecord`** SwiftData rows (**`CrashReportStore`** — per-call background **`ModelContext`**, capped at 20) and surface in **Settings → Crash Reports** (list with sent status, detail, **Share** export, **Clear All**). Opt-in developer delivery: **Settings → Share crash reports** (**`goDiveShareCrashReports`**, default off) uploads pending reports via **`CrashReportCloudUploader`** to the **CloudKit public database** (**`iCloud.PrimoSoftware.GoDiveMVP`**, record type **`CrashReport`**, oversized details as **`CKAsset`**; idempotent by UUID; readable in CloudKit Console) — no third-party crash SDK. Entitlements include iCloud **CloudKit**; the **user** SwiftData store opens with **private CloudKit** (Phase 2 — local fallback if open fails); catalog + diagnostics stores stay **`cloudKitDatabase: .none`**. **UI tests** (**`-GoDiveUITest`** / env **`GoDiveUITest=1`**): **`GoDiveUITestRootView`** only — no SwiftData init, no MapKit. **Release:** no mock seeding on launch (see **Mock data & testing**). **Snappy navigation:** agent rule **`.cursor/rules/swiftui-snappy-navigation.mdc`** — keep tab/push/sheet transitions off the main thread for heavy work; **`HomeOverviewRebuildScheduler`** coalesces Home aggregate rebuilds; foreground activation skips full rebuild when the carousel is already displayable (**`HomeReturnNavigationPresentation`**).

### Apple CloudKit — dive-log sync

**Private database** (user store): SwiftData models owned by the signed-in diver sync via **`NSPersistentCloudKitContainer`** / SwiftData CloudKit when the dual-store open succeeds. Media **bytes** stay in Photos / iCloud Photos; only pointers + preview JPEGs sync. **`UserProfileCloudKitIdentityMerge`** collapses duplicate Apple-ID profiles after import.

**Public database:** opt-in crash diagnostics only (**`CrashReportCloudUploader`**).

### Firebase — social directory, friends, catalog CDN

**Friends:** QR / link invites (`friendInvites`), mutual **`friendships`**, Profile **☰** menu → **Friends** list; shareable **`https://links.godiveios.com/invite/{token}`** (Universal Links + `godive://` fallback). **Friend profile** (**`FriendProfileView`**, distinct from local-only **`ViewDiveBuddyDetails`**) — Profile-style header with Firebase **`profileHeroURL`** (photo or looping video, aspect-fill clipped via **`FriendProfileRemoteHeroView`**; kind inferred from URL when Firestore kind is missing; falls back to newest shared-dive featured media via **`FriendProfileHeroPresentation`**) + avatar; same **media/map** toggle as buddy detail when hero media and map pins both exist; map pins are **blue** for shared sites and **red** for activities together (together wins at the same coordinate via **`FriendProfileSharedDiveMapPresentation`**); blue sheet pager (**`FriendProfileContentPager`**) — **Diver stats** (four highlight tiles from shared dives via **`FriendProfileLifetimeStatsPresentation`** — sighting names resolved from local Field Guide / user catalog by **`catalogUUID`**, no leaderboard taps) → **Activities** (pinned title + trailing glass **All** / **Together** **`FriendProfileActivityFilterToggle`** + **`FriendProfileSharedDivesPanel`** → **`FriendSharedDiveDetailView`**) → **Shared media** grid (**`FriendProfileSharedMediaPanel`**, pinned title; fullscreen via **`FriendSharedMediaFullscreenView`** — same Linked-style playback as local buddy tagged media (custom pager, vertical dismiss, center play/pause; view-only tag chrome)); no DAN/certs. Owner hero sync: **`GoDiveProfileHeroFirestoreSync`** (debounced when the profile hero changes); starring **your** tagged header media (**`GoDiveProfileHeroFeaturedMediaSync`**) force-reuploads hero bytes + merges Firestore fields for friends. **Invite accepted push:** FCM token at **`users/{uid}/private/fcm_*`**; Cloud Function **`notifyFriendInviteAccepted`**; tap opens Logbook **Friends**. **Buddy activity shared push:** client **`create()`** on **`users/{uid}/buddySharePushSignals/{activityId}`** when the projection is **first** written (existing **`sharedDives`** docs and local **`friendSharePushSignalRecorded`** — hydrated from Firebase on republish — skip); full republish never wipes projections while sharing is still on (friends-graph lag used to delete+recreate and re-notify); Cloud Function **`notifyBuddyActivityShared`** **`onDocumentCreated`** on that path (not **`sharedDives`** merges), batches a 20 s window per poster into **one** push (*"{Name} logged a new dive/snorkel."* / *"{Name} shared N new activities."*; tagged recipients get *"{Name} tagged you in a new dive/snorkel."* / *tagged you in N new activities.* instead), and permanently dedupes activity IDs in server-only **`buddyActivityPush/{uid}`** so republishes / sharing off→on never re-notify; recipients = active `friendships` members minus the poster, skipping receivers who turned off **Settings → Buddy activity notifications** (default on; mirrored to `users/{uid}/private/notificationPrefs` via **`GoDiveBuddyActivityPushPreferenceSync`**). Tap routes Logbook → **Buddy Feed** (feed data loaded / retried / direct projection fetch) → activity detail for the payload activity (or latest in a batch), so Back returns to a feed that already includes it (**`GoDiveBuddyActivityPushPresentation`** + **`LogbookBuddyFeedPushDeepLinkPresentation`**; see `cursor/buddy_activity_push_notifications.md`). **Share activities with buddies** (Settings master toggle) mirrors dive and snorkel projections to **`users/{uid}/sharedDives`**; owned activity detail (**⋯** toolbar) opens **Activity Settings** (blue overview-panel modal — Cancel / Done, large detent) — per-activity buddy sharing toggles (activity / media / **Share private notes with buddies**), checkbox media grid, **Activity / Media / Private Notes** status checklist, and **Delete dive** / **Delete snorkel** pinned at the bottom (permanent local + CloudKit removal, Firebase projection cleanup, marine-life / tag / buddy cleanup). **Local-first publish checkpoint (Strava-style):** new activities (import + manual) seed with sharing **off** and **`friendSharePublishCheckpointPending`**; when the owner has buddies, owned dive/snorkel map detail overlays **`ActivityPublishCheckpointBanner`** just above the sheet seam (GoDive title ocean gradient fill; **Share with Buddies?** + subtitle pointing at the **⋯** menu) — visible at **large** detent only (hidden when minimized). One-tap **Share** (**`ActivityFriendSharePublishCheckpoint.publish`** → per-activity share on, `scheduleUpsert`, projection + buddy push signal) or **×** dismiss; opening **Activity Settings** also clears the pending flag. Pre-existing activities are unaffected (backfill never sets the flag). Push signal docs require owner **read** on **`buddySharePushSignals`** for create-once. Schema **v3** **`mediaItems`**: true two-phase publish — phase one uploads **thumbnails only** (stored 256 px previews, no PhotoKit content export) and checkpoints **`GoDiveSharedMediaPublishState`** per item; **`GoDiveSharedMediaUploadQueue`** lazily exports + uploads full JPEG / 1080p MP4 from `photosLocalIdentifier` (2-way concurrency, per-object checkpoints) and patches Firestore when done. PhotoKit / JPEG encode / SHA-256 / Storage content uploads and LZFSE profile/swim track encode run **off the main actor** (**`GoDiveSharedMediaExport`**, **`GoDiveSharedMediaUpload.performContentPhase`**, detached track codecs); scheduling + SwiftData reads stay on main. ### Google Maps — auth model (no user OAuth today)

The **Maps SDK for iOS** authenticates with a **server-side API key** bundled in the app (see **Secrets / setup** above). It does **not** sign the user into a Google account or send dive log data to Google for basic tile + marker display.

**Not required for current spike:** Google **OAuth consent screen** or “share data with Google Maps” user flow.

**Revisit before adding:** Google **Places** (autocomplete / search), **Routes**, **Geocoding** as a billed Google REST API, **Google Sign-In**, or any API that reads a user’s Google account or sends user-generated dive content to Google backends — those may need a privacy-policy update, OAuth consent configuration, and/or additional API enablement. Track in **`cursor/todo.md`** → **Google Maps / Google Cloud**.

### Fishial.AI — optional cloud fish identification

GoDive depends on **[Fishial.AI](https://fishial.ai/)**’s hosted **Recognition API v2** for the manual **Identify fish** flow on dive media (pink→purple gradient **sparkles** beside **+** on the **Marine life** tag sheet leading toolbar). The feature is **off unless configured**: **`FishialSecretsBootstrap`** loads **`ClientID`** / **`ClientSecret`** from gitignored **`GoDiveMVP/Config/FishialSecrets.plist`** (free developer keys from [portal.fishial.ai](https://portal.fishial.ai)).

**Selection UX:** photos open the crop editor on a fast local preview (**`.fastFormat`**, **1024** edge); videos scrub on the lighter **`.homeCarousel`** stream with a live-updating **`AVAssetImageGenerator`** still preview (not keyframe-snapped **`AVPlayer`** seeks) that refreshes as the slider drags — requests are coalesced (**`FishialVideoScrubFrameRequestCoalescer`**: one decode at a time, newest fraction runs next) at a small **±0.05 s** tolerance so intermediate frames show instead of only the frame after the finger lifts — and duration from **`PHAsset`** metadata — full iCloud originals load only when the user taps **Identify** / **Continue**. **What leaves the device:** one **JPEG still** per identify (user-cropped full-quality photo export or cropped scrubbed video frame) via **`POST /v2/recognize`**, plus optional dive coordinates in the **`Fishial-Location-Lat-Lon`** header when the associated **`DiveActivity`** has a resolvable map coordinate (linked site, entry GPS, or catalog name match). **No automatic batching** — the user must tap **Identify** after framing the fish in the crop editor (videos: scrub → **Continue** → crop → **Identify**).

**What stays local:** PhotoKit originals, the full dive log, and Field Guide catalog data. Fishial returns species candidates only; GoDive **fuzzy-matches** those scientific names against the bundled **`MarineLife`** catalog (**`FishialMarineLifeCatalogMatching`**) and shows catalog thumbnails in the review sheet. When the user confirms a match (single result) or picks one from multiple, GoDive creates a **`SightingInstance`** tag on that catalog species (**`MarineLifeSightingRecorder.tagSpecies`**) and saves the catalog scientific name on **`DiveMediaPhoto.fishialConfirmedSpeciesName`**; the matching species oval at **medium** / **large** shows an in-chip **sparkles** badge.

**Operational notes:** requires network and a signed-in profile to save catalog tags; subject to Fishial account credits, API availability, and their [API terms / privacy policy](https://docs.fishial.ai/api). Client code: **`FishialAPIClient`**, **`FishialObservationLocation`**, **`DiveMediaFishialIdentification`**, **`FishialMarineLifeCatalogMatching`**, **`DiveMediaFishialIdentificationStorage`**, **`FishialIdentificationReviewPresentation`**. Revisit privacy copy and App Store disclosures before shipping identify broadly or enabling background/auto-identify.

**Manual media tagging:** **`DiveMarineLifeTagPickerSheet`** (blue **`.large`** Cancel / **+** / Done modal) stages catalog picks until trailing **Done** commits **`MarineLifeSightingRecorder.tagPendingSpecies`**; **Cancel** discards staged tags; **+** opens **`FieldGuideMarineLifeAddSheet`** and stages the new species; buddy tag picker uses the same blue overview-panel chrome.

## Data storage strategy

- **Single source of truth (on device):** Durable dive, account, catalog, equipment, certification, trip, and field-guide data lives in **SwiftData** via **`AppSwiftDataSchema`** / **`AppModelContainer`**. Production opens **four on-disk configurations** — **user** (**`GoDiveUser`**, private CloudKit), **user-local** (**`GoDiveUserLocal`**, **`DiveProfilePoint`** only, CloudKit off), **catalog** (**`GoDiveCatalog`**, local), **diagnostics** (**`GoDiveDiagnostics`**, local). There is **no archive of raw import file bytes** (**.fit** / **.uddf**) after import.
- **Hybrid cloud sync (implemented):** **`cursor/hybrid_cloud_sync_boundaries.md`** freezes Option A boundaries; **`cursor/hybrid_cloud_sync_phase1_migration.md`** covers the dual-store plan. Phase 1 adds partition lists, CloudKit-shape prep, ownership flags, **`photosCloudIdentifier`**, and UUID-only **`UserMarineLife` / `UserDiveSite`**. Production opens split on-disk stores via **`AppSwiftDataDualStoreBootstrap`**. **Phase 2** enables **private CloudKit on the user store** (local fallback if open fails **without deleting** existing stores; sticky local-only after fallback; diagnostics in Application Support / **`cloudkit-open-diagnostics.txt`**). **Policy v7:** depth-profile **rows** stay local; full tracks sync as compressed **`DiveActivity.profileTrackData`** so CloudKit is not blocked by hundreds of thousands of sample records. **Policy v8:** **`SnorkelActivity.owner`** gained its required CloudKit inverse on **`UserProfile`** — clears sticky local once so devices that fell back retry CloudKit, and **`AppSwiftDataDualStoreMigrator`** copies snorkel activities when a parked store is recreated. **Snorkel sessions** mirror on the same private user store as dives (**`SnorkelActivity`**, buddies, media pointers); **`SnorkelActivityOwnership.claimUnownedSnorkels`** adopts orphan snorkels on sign-in; GPS/HR tracks sync as compressed **`SnorkelActivity.swimTrackData`** (**`SnorkelSwimTrackCodec`**) while **`SnorkelProfilePoint`** rows stay in **`GoDiveUserLocal`**. **Launch:** session restore dismisses the splash after a short (~25s) profile wait; Firebase/iCloud population continues in the background without blocking the overlay. **Import speed:** CloudKit dive-log sync runs in parallel with Firebase population; store open kickstarts mirroring; import notifications wake the session sync loop (150ms poll fallback); foreground keeps the process warm ~8s while the log is still empty. Sync may use **cellular or Wi‑Fi**; **`GoDiveCloudKitBackgroundSync`** schedules **BGAppRefresh** / **BGProcessing** so mirroring can continue in the background when iOS allows (processing does **not** require external power). CloudKit-safe schema: optional to-many `*Storage` relationships, GPS Doubles, JSON list **`Data`**, raw-string enums. ## Dive file import (Garmin FIT + UDDF)

- **FIT — dependency:** Swift package **[FITSwiftSDK](https://github.com/garmin/fit-swift-sdk)** (v21.x+) on **`GoDiveMVP`**; see **External dependencies** for the full dependency table.
- **FIT — decode + map:** **`Data/Import/FitDiveFileDecoder.swift`** — **`Decoder`** + **`FitListener`**; **`FitActivitySessionValidation`** requires **`Sport.diving`** with **`SubSport`** **Single-Gas**, **Multi-Gas**, **CCR**, or **Gauge** (rejects snorkel/open-water files early); exactly **one** diving session per file; **`DiveActivity`** (**`source: .garminMK3`**, **`rawImportVersion`**); **`DiveSummaryMesg`** (session-linked) for **`bottomTimeSeconds`** / **`surfaceIntervalSeconds`**; **`DiveImportWaterTemperatureSummary`** for **`waterTemp*Celsius`**; **`DiveProfilePoint`** from **`RecordMesg`** (depth, time, temp, NDL, time-to-surface, instantaneous **ascent rate** m/s, optional per-sample **`tankPressurePSI`** from **`TankUpdateMesg`** time-alignment, optional **`heartRateBPM`**, **`po2Bars`**, **`n2Load`**, **`cnsLoad`** when present in the file); **entry GPS** from **`SessionMesg.start_position_*`** when set, else first **`RecordMesg`** position (invalid semicircle **`0x7FFFFFFF`** skipped); **tank** dive-level fields from **`TankSummaryMesg`** / **`TankUpdateMesg`** via **`FitTankFieldImport`** (bar→psi; **≤2** tank sensors; **`>2`** sensors or **>1** diving session → **`FitDecodeError`**); **gas** from **`DiveGasMesg`** (**`oxygenMix`** %, **`gasType`** **Air** / **Nitrox** via **`DiveGasMixImport`**); **`sourceDiveId`** from **`FileIdMesg`**. **`FitDecodeError`** for invalid FIT.

## Mock data & testing

- **Policy:** Non-trivial **`GoDiveMVP/`** changes should add or update tests in **`GoDiveMVPTests`** or **`GoDiveMVPUITests`** (see **`.cursor/rules/code-changes-require-tests.mdc`** and **`cursor/rules.md`**). Concurrency: **`@MainActor`** for UI state only; heavy SwiftData / compute off-main (**`.cursor/rules/swift-mainactor-usage.mdc`**, **`swiftui-snappy-navigation.mdc`**).
- **Debug builds:** **`MockDataSeeder`** available but **disabled** at launch by default; set **`MockDataSeeding.isLaunchSeedingEnabled`** to load bundled JSON. **Release:** never seeds on launch.
- **Unit tests:** **`GoDiveMVPTests`** — Swift Testing, logic-focused: matchers, **`.fit`** / **`.uddf`** import decoders + outcomes, **`DiveActivityDuplicateMatcher`**, **`DiveSACRMVCalculation_*`**, depth-profile math, **`diveLocationMapPresentation_*`** (incl. **`adjustedMapCenter`** with top + bottom obstructions), **`diveMapCoordinateResolver_*`**, **`diveActivityOverviewDetent_*`**, **`diveActivityOverviewPanelMetrics_*`** (scroll snap, detent helpers), tank tab (**`diveActivityTankPanelSummary_*`**), tab icons, **`DiveQuantityFormatting`**, **`DiveActivityDeletion`**, **`AppUserSettings`**, **`FitTankFieldImport_*`**, etc. Value types used from nonisolated tests (**`FieldGuideCategorySummary`**, **`FishialRankedSpecies`**, **`DiveActivityMapOverviewStatIcon`**, etc.) are **top-level** with explicit **nonisolated** **`Equatable`** / **`Hashable`** where needed (Swift 6 + **`SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`**).
- **Agent run/test:** **`.cursor/rules/xcode-run-test.mdc`** — when asked to run or test the app, the agent runs **`xcodebuild clean`**, then **`clean build`** / **`clean build-for-testing`** (e.g. Dre's Phone or iPhone 17 simulator), and reports compiler errors/warnings before handing off.
- **UI tests:** **`GoDiveMVPUITests`** — **`XCUIApplication.goDiveForUITesting()`** launches **`GoDiveUITestRootView`** (stable AX shell, not production **`ContentView`**). **`testLaunch`**: **`GoDive.UITest.Root`**, Home tab, Profile. Scheme: test bundles **`parallelizable = "NO"`**; **`runsForEachTargetApplicationUIConfiguration = false`**.
- **Manual:** **⌘R** in Debug on simulator/device with fixtures; previews where present.
- **TestFlight / beta distribute:** **`cursor/testflight_setup.md`** — App Store Connect app record, Release archive upload, Internal vs External TestFlight, release gates, secrets, production APNs.
